Hi, I'm **Sumit Panchal**, a Quality Analyst passionate about software quality, user experience, and building reliable digital products.

My testing approach focuses on **quality, usability, reliability, consistency, and real-world user behavior**.

## 🧠 QA Mindset

> **Testing is not just about checking whether the feature works.
> It's about understanding what can go wrong before the user finds it.**

My QA mindset focuses on:

* Understanding requirements before testing
* Thinking from the user's perspective
* Testing beyond the happy path
* Finding edge cases and unexpected behavior
* Validating UI consistency and usability
* Identifying defects early
* Creating clear and reproducible bug reports
* Collaborating with developers and stakeholders
* Continuously improving product quality
